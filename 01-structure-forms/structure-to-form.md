# 结构类型 → 常用形式

> 初稿，内容来自通用知识，尚未逐项核验，也没有经过作者确认。用来占位和调整分类，不当作结论。

| 结构类型 | 常用形式 | 擅长 | 容易出问题的地方 |
| --- | --- | --- | --- |
| 层级 / 包含 | 缩进树、树图（tree）、treemap、sunburst / icicle、circle packing | 看层级归属，可带占比 | 跨层级的横向关系看不出 |
| 网络 / 关系 | 节点连线图（node-link）、弧线图、邻接矩阵 | 小而稀疏的网络用节点连线图直观 | 网络变密后节点连线图易成"毛球"，矩阵更稳 |
| 依赖 / 耦合 | 依赖图、依赖结构矩阵（DSM）、边捆绑（edge bundling） | 看模块间依赖、循环依赖、聚类 | 依赖图在规模大时难读；矩阵需要排序才有信息 |
| 流程 / 控制流 | 流程图、泳道图、BPMN、状态机图 | 阶段、分支、参与者、状态流转 | 并行和时间信息表达弱 |
| 时序交互 | 时序图（sequence diagram） | 对象之间按先后顺序的消息 | 参与者多时横向过宽 |
| 带时间的执行轨迹 | Trace 瀑布图、火焰图、甘特图、时间线 | 耗时、串并行、嵌套调用 | 看不出静态结构 |
| 量在节点间流动 | 桑基图、弦图 | 流量、转化、分配 | 节点和流太多时拥挤 |
| 因果 / 反馈 | 因果回路图、存量流量图 | 反馈环、增强与平衡 | 容易画成"什么都连"，需要明确变量定义 |
| 多维属性 | 散点图矩阵、平行坐标、降维散点图 | 比较多个属性、看聚类 | 降维后轴没有直接含义 |
| 概念 / 论证 | 概念地图、思维导图、论证地图 | 概念包含、推论、冲突与证据 | 缺少统一语义时随意性大 |
| 架构多视角 | C4 模型（context / container / component / code）、多视图 | 同一系统按不同抽象层级分图 | 视图之间的一致性需要靠模型保证 |
