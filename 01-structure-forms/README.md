# 01 图表与展示技术的理论归类

回答的问题：**什么结构的数据，展示成什么样子。**

这一层偏理论：对图表和展示技术进行归类，讨论每一类适合表达什么、不适合表达什么。具体实现用的库和引擎不放这里，见 [第 2 层 a](../02-visualization-stack/a-technology/)。

目前的归类轴是"数据是什么结构"。同一种结构往往有多种形式（例如依赖网络既可以画成节点连线图，也可以画成矩阵），每种形式适合的任务不同。是否还要增加别的归类轴（比如按任务），待定。

## 内容

- [`structure-to-form.md`](structure-to-form.md)：结构类型 → 常用形式的对照表（初稿）。
- 之后可按需要增加单个形式的详细条目。
