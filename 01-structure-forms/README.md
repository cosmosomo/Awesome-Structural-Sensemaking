# 01 结构展示流派与技术

回答的问题：**什么结构的数据，展示成什么样子。**

入口是"数据/对象是什么结构"，而不是"有哪些图表库"。同一种结构往往有多种形式（例如依赖网络既可以画成节点连线图，也可以画成矩阵），每种形式适合的任务不同。

## 内容

- [`structure-to-form.md`](structure-to-form.md)：结构类型 → 常用形式的对照表（初稿）。
- 之后可按需要增加：单个形式的详细条目、实现这些形式的技术与引擎。

## 条目模板

```markdown
### 形式名称
- 结构类型：
- 适合的任务：
- 不适合 / 易踩坑：
- 实现技术（库、引擎）：
- 例子（链接）：
```
