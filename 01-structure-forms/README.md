# 板块 1 结构与可视化范式

回答的问题：**什么样的数据和结构，适合用什么形式表达。**

这个板块偏理论：对图表和展示技术进行归类，讨论每一类适合表达什么、不适合表达什么。

区分三个概念：

- 数据结构：树、网络、有向无环图、时间序列、多维数据等；
- 视觉表达：树图、拓扑图、流程图、时序图、矩阵、桑基图等；
- 技术实现：图形库、布局算法、渲染技术等。

本板块讨论前两者之间的对应。技术实现放在 [板块 2 的 a](../02-visualization-stack/a-technology/)。

目前的归类轴是"数据是什么结构"。同一种结构往往有多种形式（例如依赖网络既可以画成节点连线图，也可以画成矩阵），每种形式适合的任务不同。是否增加别的归类轴（比如按任务），待定。
