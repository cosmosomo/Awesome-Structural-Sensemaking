# 交互范式的分类

交互不是底层库的附属功能，而是一套独立的分类。

| 交互流派 | 具体操作 | 认知作用 |
| --- | --- | --- |
| 导航 | 缩放、平移、定位、搜索 | 在庞大结构中找到对象 |
| 层次探索 | 折叠、展开、钻取、上卷 | 在全貌与细节间切换 |
| 复杂度管理 | 聚合、抽稀、过滤、边捆绑 | 减少视觉拥挤 |
| 关系探索 | 高亮邻居、路径追踪、依赖影响分析 | 聚焦特定关系 |
| 多视角协同 | 图表联动、视角切换、局部与全局同步 | 从不同侧面理解同一对象 |
| 时间探索 | 播放、暂停、时间筛选、历史比较 | 理解运行过程与变化 |
| 编辑与重构 | 修改节点、关系、分组、布局 | 从观察进入结构构建 |
| 分析与推演 | 结构指标、异常识别、模拟、方案比较 | 从展示进入发现和决策 |

## 折叠不只是隐藏

在复杂网络中折叠一个子系统之后：

- 原来连接子系统内部节点的跨模块边应该如何处理？
- 如何合并为聚合边，并保留方向、数量和关系类型？
- 展开后又如何恢复？

这些问题同时涉及结构语义、图算法、布局稳定性和交互设计。结构聚合算法（决定显示哪些对象、合并哪些关系）与视觉布局算法（决定这些对象显示在哪里）应当分开研究。

可以直接对照的实现见第二板块 L1 的 [关系图引擎](../02-visualization-ecosystem/L1-foundational-technologies/README.md) 一节。
