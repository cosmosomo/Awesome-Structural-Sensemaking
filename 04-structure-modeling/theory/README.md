# 信息结构理论

回答的问题：**不同的信息结构各自是什么，有什么性质，能表达什么、不能表达什么。**

属于 [板块 4](../)，与 [提炼方法](../extraction/) 强关联：extraction 讲怎么提炼，这里讲提炼出来的结构本身。条目之间互相引用。

## 范围

- 各类信息结构的定义与性质。
- 不同结构之间的区别、转换与相互表达。
- 一种结构的表达能力与局限。

具体包含哪些结构类型，待你确定。[板块 1](../../01-structure-forms/structure-to-form.md) 表格里出现的类型（层级、网络、依赖、流程、时序、因果、多维、概念 / 论证等）可作为起点，但不代表这里的分类。
