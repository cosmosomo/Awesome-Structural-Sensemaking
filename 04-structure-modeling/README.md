# 板块 4 结构提炼与认知建模

回答的问题：**如何从信息和认知中发现结构，分层，并把握抽象层级和颗粒度；以及这些结构本身是什么。**

分成两个强关联的部分，条目之间互相引用：

| 部分 | 目录 | 记录什么 |
| --- | --- | --- |
| 提炼方法 | [`extraction`](extraction/) | 从信息和认知中提炼结构的方法：怎么提炼、怎么分层、怎么控制粒度。 |
| 信息结构理论 | [`theory`](theory/) | 不同信息结构的理论讨论：各类结构的性质、能表达什么、不能表达什么。 |

提炼方法要落到某类目标结构上，目标结构的性质在 theory 里讨论。

下面是另一份建议里列出的，还没经过确认：

| 层次 | 研究内容 |
| --- | --- |
| 信息识别 | 从文章、代码、对话、系统、经验中识别有意义的信息 |
| 概念抽象 | 如何提炼概念、类别、实体、属性与关系 |
| 层级建模 | 如何划分系统、子系统、模块、个体与细节 |
| 粒度控制 | 哪些信息应当聚合，哪些必须保留独立性 |
| 多维结构 | 如何同时描述层级、依赖、时序、因果和其他关系 |
| 认知整合 | 如何将新信息放入已有认知框架，而不丢失原始内容 |
| 结构评价 | 如何判断抽象是否合理、知识是否完整、层级是否一致 |
| 结构重构 | 如何在认识变化后修订结构，同时保留有价值的旧知识 |
