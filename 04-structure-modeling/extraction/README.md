# 提炼方法

回答的问题：**面对混乱的信息和脑中的认知，如何提炼出结构。**

属于 [板块 4](../)，与 [信息结构理论](../theory/) 强关联：提炼方法要落到某类目标结构上，目标结构的性质在 theory 里讨论。条目之间互相引用。

## 范围

- 从信息中提炼结构（文章、代码、聊天记录、观察结果等）。
- 从认知中提炼结构（把脑中的想法外化）。
- 如何分层提炼。
- 如何把握抽象层级和颗粒度。

## 条目模板

```markdown
### 方法 / 文章 / 论文名
- 针对的输入（什么样的信息或认知）：
- 提炼出的结构类型（回指 theory）：
- 如何分层、如何把握颗粒度：
- 链接：
- 备注：
```
