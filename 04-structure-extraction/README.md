# 04 从信息与认知中提炼结构

回答的问题：**面对混乱的信息和脑中的认知，如何提炼出结构。**

## 范围

- 从信息中提炼结构（文章、代码、聊天记录、观察结果等）。
- 从认知中提炼结构（把脑中的想法外化）。
- 如何分层提炼。
- 如何把握抽象层级和颗粒度。

## 与第 5 层的关系

第 4 层与第 5 层强关联：提炼方法要落到某类目标结构上，目标结构的性质在第 5 层讨论。条目之间互相引用。

## 暂放在这里的内容

- 写文章如何写出立体认知（归属待确认）。
