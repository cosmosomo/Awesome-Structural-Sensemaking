# 03 项目索引与评估

回答的问题：**一个更广的项目，内部有哪些可视化，做得怎么样。**

例如一个多智能体管理项目，内部可能同时有工作流编辑器、运行 Trace、成本面板等多种可视化。第 3 层以项目为单位，逐项记录并评估，评估表回指第 1 层和第 2 层。

> 本层与 [第 2 层 c](../02-visualization-stack/c-applications/)（成熟应用中的交互）的对象重叠，分工待定。

## 评估表模板

每个项目一张表，一行一个可视化：

| 可视化项 | 对应的数据与层级（第 2 层 b） | 结构类型与形式（第 1 层） | 交互 | 评价 | 依据 |
| --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |

评价先用简短文字。是否引入评分维度，等收集几个项目之后再定。

"依据"写明评价来自什么：实际使用、官方 Demo、截图，还是只读了文档。
