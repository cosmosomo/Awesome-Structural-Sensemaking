# Awesome Structural Sensemaking

复杂的信息、知识、系统和认知，如何被提炼为结构，又如何通过合适的表达方式，使人能够理解、探索、分析和重构这些结构？

本库研究如何把脑中的认知和复杂系统转化为清晰的结构，并通过图、交互网页、三维/多维、折叠，以及分层的文章表达出来。两个方向都收：

- 已有结构如何可视化（结构已知 → 选择形式、技术、交互）；
- 如何从混乱的信息和认知中发现结构（结构未知 → 提炼、分层、把握抽象层级与颗粒度）。

> 本仓库处于起步阶段，目录与文字为初稿，随收集内容调整。

| 3 综合项目可视化案例 | [`03-project-index`](03-project-index/) | 一个真实的大型产品或系统，内部用了哪些可视化，做得怎么样？ | 更广的项目索引，逐项分析内部的可视化，用表格评估。 |

## 板块之间

- 四个板块是四种不同的研究对象，不是从低到高的步骤，可以从任何一个进入。
- 一个条目可以被多个板块引用，不强制只放进唯一的分类。
- 所有条目尽量回答同一套问题，见 [`entry-fields.md`](entry-fields.md)。

已确定的内部关系：

- 板块 2 内部由底向上分层：底层可视化技术 → 针对某类数据的可视化项目 → 成熟应用中的交互。
- 板块 4 内的提炼方法与信息结构理论强关联，互相引用。
