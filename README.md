# Awesome Structural Sensemaking

研究如何把脑中的认知和复杂系统转化为清晰的结构，并通过图、交互网页、三维/多维、折叠，以及分层的文章表达出来。

两个方向都收：

- 已有结构如何可视化（结构已知 → 选择形式、技术、交互）；
- 如何从混乱的信息和认知中发现结构（结构未知 → 提炼、分层、把握抽象层级与颗粒度）。

> 本仓库处于起步阶段，目录与定位文字为初稿，随收集内容调整。
