# 02 领域与层级的可视化展开

回答的问题：**某个领域里，不同层级各自怎么可视化，有哪些项目。**

按"领域 → 层级"组织。同一领域的不同层级关心的结构不同（例如多智能体的协作层看角色与交接，Trace 层看一次运行里的事件与耗时），所以分开记录。

## 领域

- [`multi-agent`](multi-agent/)：多智能体

其他领域（如软件架构与模块解耦、知识与概念体系、业务流程）待补。

## 条目模板

```markdown
### 项目名
- 领域 / 层级：
- 可视化的是什么结构：
- 使用的形式（回指第 1 层）：
- 交互：
- 链接（仓库、Demo）：
- 备注：
```
