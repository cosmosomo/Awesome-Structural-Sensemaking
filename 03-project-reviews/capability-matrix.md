## 单项目评估表模板

每个项目一张表，一行一个可视化。**被表达结构的复杂度**和**观察到的理解难度**分开记，不合并成一个分数（见[评价理论](../01-theory/evaluation-theory.md)）。

| 可视化项 | 对应的数据与层级 | 结构类型与形式 | 被表达结构的复杂度（规模、层数、关系种类等） | 任务与使用者 | 观察到的理解难度 | 交互 | 评价 | 依据 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| | | | | | | | | |

- “任务与使用者”必填：难度只对具体任务和具体使用者有意义。
- “依据”写明评价来自什么：官方文档、源码、公开 Demo，还是亲自实测。

## 多智能体管理平台的观察项（示例）

| 观察项 | 观察内容 |
| --- | --- |
| 整体架构 | 是否有全局架构视图？ |
| 协作关系 | 能否展示智能体之间的通信与任务交接？ |
| 流程编排 | 是否支持节点式流程编辑与执行展示？ |
| Trace | 是否支持调用树、时间轴、嵌套事件分析？ |
| 抽象层级 | 能否展开、折叠、聚合、钻取？ |
| 视角联动 | 架构、协作、任务、Trace 等视角能否互相映射？ |
| 交互质量 | 是否支持筛选、搜索、高亮、回放？ |
| 实现方式 | 使用哪些图形技术、数据模型和组件？ |
| 不足与机会 | 哪些重要的信息和关系没有得到表达？ |
