# 2c 成熟应用中的交互

回答的问题：**在成熟的应用项目里，可视化嵌在怎样的交互之中。**

可视化只是应用的一部分。这里关心的是围绕可视化的整体交互：用户如何在可视化和应用的其他部分之间切换、操作和反馈。
