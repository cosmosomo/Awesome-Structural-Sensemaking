# 2b 针对某类数据的可视化项目

回答的问题：**针对某一类具体的数据，有哪些可视化项目，各自怎么展示。**

按"领域 → 层级"组织。同一领域的不同层级关心的数据不同（例如多智能体的协作层看角色与交接，Trace 层看一次运行里的事件与耗时），所以分开记录。

## 领域

- [`multi-agent`](multi-agent/)：多智能体

## 候选领域与层级（参考稿，待确认）

下面是另一份建议里列出的，除多智能体的协作层和 Trace 层外，都还没经过确认：

| 领域 | 可研究的抽象层级或视角 |
| --- | --- |
| 多智能体系统 | 全局协作、组织架构、任务路由、个体决策链、工具调用、Trace |
| 软件工程 | 系统架构、模块关系、类与函数依赖、运行调用、代码执行 |
| AI 技术生态 | 技术分类、能力依赖、开源项目关系、技术与产品映射 |
| 知识与认知 | 知识体系、概念网络、论证结构、分层文章、认知地图 |
| 业务系统 | 组织、业务功能、业务流程、执行状态、事件 |
| 复杂动态系统 | 个体关系、宏观结构、状态演化、反馈回路 |
