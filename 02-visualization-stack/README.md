# 板块 2 领域与层级可视化

回答的问题：**不同领域、不同层级的系统，如何可视化。**

这是最复杂的板块，由底向上至少分三个子层，后续可能继续细分：

| 子层 | 目录 | 记录什么 |
| --- | --- | --- |
| a | [`a-technology`](a-technology/) | 底层可视化技术。 |
| b | [`b-data-specific`](b-data-specific/) | 针对某一类数据的具体可视化项目，例如多智能体的协作层、Trace 层。 |
| c | [`c-applications`](c-applications/) | 成熟应用项目中的交互。可视化只是应用的一部分，这里关心可视化如何嵌在整个应用的交互里。 |

## 与其他板块的关系（初稿，待确认）

- b、c 用到的展示形式，回指板块 1。
- b 用到的底层技术，回指 a。
- c 与板块 3（综合项目可视化案例）的对象都是成熟应用，二者的分工待定，见 [`c-applications`](c-applications/)。
